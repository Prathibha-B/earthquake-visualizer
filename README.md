# 🌍 Earthquake Visualizer

An interactive web app that displays real-time earthquake data on a world map using Leaflet and React. Users can filter earthquakes by magnitude and toggle between light and dark themes.

## Features

- Real-time data from USGS Earthquake API
- Interactive map with color-coded markers by magnitude
- Magnitude filter slider
- Dark mode toggle
- Responsive design for desktop and mobile
- Graceful error handling and loading spinner

## Tech Stack

- React
- Leaflet (via react-leaflet)
- JavaScript (ES6+)
- HTML/CSS
